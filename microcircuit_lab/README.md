# Microcircuit Lab: the core

This folder is the core package: it reads network files, checks them, runs them in NEST or Brian2, and plots the results. What each subfolder does is in [CONTRIBUTING.md](https://github.com/shimoura/microcircuit-lab/blob/main/CONTRIBUTING.md#package-layout).

The documentation is at https://shimoura.github.io/microcircuit-lab/, and as Markdown in [`docs/`](../docs/) next to this folder (a copy made by `init --with-core` has it too):

- Getting started: [Installation](../docs/installation.md), [Your project](../docs/project.md), [Tutorials](../docs/tutorials/)
- Guides: [How it works](../docs/how-it-works.md), [Network files](../docs/network-files.md), [Weights and delays](../docs/weights-and-delays.md), [Connections](../docs/connections.md), [Scaling a network model](../docs/scaling.md), [A new network model](../docs/new-network.md), [Running from a script](../docs/scripts.md), [The run folder](../docs/run-folder.md), [Analysing a run](../docs/analysis.md), [NEST](../docs/nest.md), [Brian2](../docs/brian2.md)
- Reference: [Configuration files](../docs/config_files.md), [From a builder to the plots](../docs/workflow.md)
